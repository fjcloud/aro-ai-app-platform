Validated on the assigned `lvdw8` ARO lab on 28–29 October 2026 (OpenShift 4.21.22). The public application, rather than a local proxy, passed the browser replay.

- **Platform:** installed the workshop operators, CPU worker and one `Standard_NC8as_T4_v3` GPU worker. Native d3-mini reports `cuda:0`, FP16, with one 16 GB T4. The documented curl probes, formatted with jq, scored the same news differently for semiconductor and retail memos.
- **Model access:** Azure DeepSeek-V4-Pro `2026-04-23`, published through OpenShift AI MaaS, with separate coding and app subscriptions. Native Gen AI Responses, streaming/tool calls and rejection of invalid credentials passed. No Foundry key is supplied to the app or workspace.
- **Development and delivery:** DeepSeek in OpenCode reused the complete reference, built/tested the Go app in Dev Spaces, committed/pushed to personal Git, then delivered through Tekton and Argo CD. It also generated the relevance checkbox. Maintainer fixes preserve hidden controls and finish native research with no further tools plus a strict JSON schema once all required evidence is available. Final source revision: `d36a88813816605c4142152aa6cf1835c216b8c0`; the running app digest was checked against the newly built image. Pods use restricted-v2, OAuth and the dedicated app identity.
- **Collection and recovery:** direct Techmeme collection from Azure returned HTTP 403. The browser then imported the explicitly supplied real export for 19–25 October: 289 primary stories, one disclosed unavailable ID (`261021p29`). All 289 were ranked on the ARO T4. Import validation ignores uploaded scores/research and labels the file-supplied provenance. This is not evidence that direct collection succeeds from Azure. The facilitator export CLI also requires an allowed network; its blocked local attempt was not a successful export.
- **Public browser replay:** 289/289 ranked, relevance filter, native Responses research with `read_archive`, `search_archive`, `index_universe`, export, frozen choices before price access, actual Yahoo historical prices, mobile layout and no JavaScript errors. A $1,000 SMH position entered at the 26 October open and valued at the completed 28 October close returned $68.35. The UI marked the week incomplete. The round was reset afterward and its result retained.
- **Native research reliability:** repeated live runs exposed tool-budget exhaustion and an unconstrained final answer. The client now switches to schema-constrained synthesis after successful archive read, search and catalog retrieval. The six-tool budget remains unchanged. A regression checks the handoff, and the final live acceptance repeats three fresh researches without retries. Earlier failures are retained as evidence.
- **AgentOps:** the native Playground authorized the app's MCP connector with a short-lived, app-scoped token. Its completed Responses stream contains actual `search_archive`, `list_news`, `index_universe` and `read_archive` calls. MLflow returned the app's research trace in state OK, including the agent and all three research-tool spans. All nine observability queries returned series; idle latency can be NaN.
- **Regression:** 33 workshop Python checks, 17 template checks, all five Go modules with the race detector, the browser fixture suite, vet and the Antora build passed. Fixtures cover positive/negative returns, memo edits, manual import, portfolio freezing and failure handling. Every Chromium launch used `--use-mock-keychain`.

Repeated coding tests exhausted the default five-million-token daily allowance. This lab alone was increased to 15 million for validation; source defaults remain five million. Dev Spaces idling was temporarily disabled for the unattended run, then restored to 1,800 seconds. These overrides are not normal participant prerequisites.

The exercise measures memo relevance, tool use and a historical paper outcome. Headlines/excerpts are not full publisher articles. Imported provenance is not independently re-fetched. LLM explanations can contain reasoning errors or unsupported assumptions about holdings; inspect returned evidence. Historical model knowledge cannot be eliminated. Prices are daily observations, not executable quotes; returns exclude dividends, fees and slippage. A profitable replay is not evidence of investment accuracy.
