= AI-Powered Developer Platform on ARO

Welcome to the *AI-Powered Developer Platform on ARO* workshop.

The story for today is a Monday at a company that keeps source code on its own cluster. This morning the platform team publishes DeepSeek-V4 Pro as a managed Foundry endpoint. This afternoon a developer ships an app with it from OpenShift Dev Spaces. You wear both hats, then you look at the token bill.


== Who This Workshop Is For

[cols="1,1", options="header"]
|===
| Persona | Role in This Workshop

| *Platform Engineer* (morning)
| Publishes DeepSeek-V4 Pro on Microsoft Foundry, installs Dev Spaces, GitOps, and Pipelines, and hands developers a short `AGENTS.md`.

| *Developer* (afternoon)
| Launches OpenShift Dev Spaces, talks to OpenCode backed by that Foundry endpoint, ships a real app through Tekton and Argo CD, then asks the same model to audit the manifests.
|===

== What You Will Build

image::architecture-overview.png[Coding agent on ARO, model on Foundry, align="center"]

The LLM writes the app. DeepSeek-V4 Pro is a *platform* capability, published as a managed endpoint.

=== Act 1 — Platform
* *DeepSeek-V4 Pro* on Microsoft Foundry, Global Standard, pay per token
* *OpenShift Dev Spaces* pointed at that endpoint with one injected key
* *AGENTS.md* — the only runbook OpenCode reads
* *OpenShift GitOps* (Argo CD) and *OpenShift Pipelines* (Tekton)

=== Act 2 — Developer
* A personal Git repository on *ephemeral Git* (workshop-scoped, no GitHub account)
* A *Fortune Cookie* Go app generated live by OpenCode + DeepSeek-V4 Pro
* Image build and GitOps deploy from git, ephemeral Git, and `oc` — no Ansible, no local Docker
* Platform rules (limits, probes, SCC, TLS) audited by the same model

=== Act 3 — The bill
* Input and output tokens from the afternoon, priced from the Foundry list rate
* Delete the deployment when the day is over so nothing is left reserved

== Learning Outcomes

After completing this workshop, you will understand:

* How a Foundry Global Standard deployment publishes an OpenAI-compatible model without a GPU node
* How `AGENTS.md` shifts platform governance from documentation to something the model enforces
* How Dev Spaces + OpenCode is an AI-augmented inner loop with no laptop install
* How Tekton and Argo CD form a GitOps path from a single repository
* How input and output tokens are the bill for a managed coding model
