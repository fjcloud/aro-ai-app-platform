= Lab 1.3 — Hand DeepSeek to Dev Spaces

Operators are still installing. Wait until Dev Spaces, GitOps, and Pipelines are up, then store the Foundry endpoint where OpenCode will read it. Developers get one base URL and one key. They do not get a GPU, a vLLM pod, or `api.openai.com`.

[NOTE]
====
*Estimated time:* 15 minutes +
*Persona:* Platform Engineer +
*Needs:* `state/foundry.env` from Lab 1.1, in this repository
====

== Why a managed endpoint

The cluster stays a place to edit, build, and deploy. The model stays on Foundry.

[cols="1,2", options="header"]
|===
| What the developer sees | What it is

| `$OPENAI_BASE_URL`
| `https://<account>.cognitiveservices.azure.com/openai/v1`

| `$OPENAI_API_KEY`
| The Foundry account key, injected into every Dev Spaces workspace

| Model id
| `deepseekv4pro` — the deployment name from Lab 1.1
|===

Same JSON as a cloud OpenAI chat call, different host:

[source,sh]
----
curl "${OPENAI_BASE_URL}/chat/completions" \
  -H "api-key: $OPENAI_API_KEY" \
  -d '{"model": "deepseekv4pro", "messages": [{"role": "user", "content": "Hello"}]}'
----

== Step 1: Create Dev Spaces

This creates the Che cluster, the OpenCode tool registry, and the workspace model pin. It does not create a GPU policy or a serving stack.

[source,sh,role=execute]
----
oc apply -f deploy/instances/checluster.yaml \
  -f deploy/instances/ai-tool-registry.yaml \
  -f deploy/instances/opencode-workspace-config.yaml \
  -f deploy/instances/vscode-editor-configurations.yaml

until oc get checluster/devspaces -n openshift-operators >/dev/null 2>&1; do sleep 5; done
oc wait checluster/devspaces \
  -n openshift-operators \
  --for=jsonpath='{.status.chePhase}'=Active \
  --timeout=900s
----

.Expected Output
[source,text,options=nowrap]
----
checluster.org.eclipse.che/devspaces condition met
----

Dashboard: the `cheURL` printed in Lab 1.4.

== Step 2: Store the Foundry key for every workspace

Run this in the same repository as Lab 1.1. The key is written into Secret `ai-provider-openai-api-key` and is not printed.

[source,sh,role=execute]
----
set -a
source state/foundry.env
set +a

KEY=$(az rest --method post \
  --url "https://management.azure.com/subscriptions/${SUBSCRIPTION}/resourceGroups/${RESOURCEGROUP}/providers/Microsoft.CognitiveServices/accounts/${FOUNDRY_NAME}/listKeys?api-version=${API}" \
  --query key1 -o tsv)

oc create secret generic ai-provider-openai-api-key \
  -n openshift-operators \
  --from-literal=OPENAI_API_KEY="${KEY}" \
  --from-literal=OPENAI_BASE_URL="${ENDPOINT}openai/v1" \
  --dry-run=client -o yaml | oc apply -f -

oc label secret ai-provider-openai-api-key -n openshift-operators \
  app.kubernetes.io/part-of=che.eclipse.org \
  app.kubernetes.io/component=workspaces-config \
  controller.devfile.io/mount-to-devworkspace=true \
  controller.devfile.io/watch-secret=true \
  che.eclipse.org/ai-provider-id=opencodeai-opencode \
  --overwrite
oc annotate secret ai-provider-openai-api-key -n openshift-operators \
  controller.devfile.io/mount-as=env \
  controller.devfile.io/mount-on-start=true \
  --overwrite

unset KEY
oc get secret ai-provider-openai-api-key -n openshift-operators \
  -o jsonpath='{.data.OPENAI_BASE_URL}' | base64 -d; echo
----

The printed line is the base URL only. It ends in `/openai/v1`.

== ✅ Checkpoint

[source,sh,role=execute]
----
set -a
source state/foundry.env
set +a
KEY=$(az rest --method post \
  --url "https://management.azure.com/subscriptions/${SUBSCRIPTION}/resourceGroups/${RESOURCEGROUP}/providers/Microsoft.CognitiveServices/accounts/${FOUNDRY_NAME}/listKeys?api-version=${API}" \
  --query key1 -o tsv)
curl -sS --max-time 180 "${ENDPOINT}openai/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "api-key: ${KEY}" \
  -d '{"model":"deepseekv4pro","messages":[{"role":"user","content":"Reply with one short sentence."}],"max_completion_tokens":256}' \
  | python3 -c 'import sys,json; print(json.load(sys.stdin)["choices"][0]["message"]["content"])'
unset KEY
----

You have a live DeepSeek deployment and a Dev Spaces secret that points at it. ✓
