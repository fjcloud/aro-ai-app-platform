= Lab 2.2 — Test the Model APIs

*Developer · Dev Spaces terminal.* Test each capability before writing the app.
Format JSON responses with `jq`. Keep the injected MaaS key out of Git, OpenCode
prompts and the browser.

== Two models, two jobs

*d3-mini* is a multimodal decision model: it reads an image and chooses among
supplied options, returning their probabilities. Here it decides whether an image
shows a Pokémon card and whether its printed rarity is common, uncommon or rare.
It does not generate a description or estimate market value.

*DeepSeek* generates the Go application in OpenCode and powers the runtime agent.
The agent verifies the selected catalogue reference through a read-only MCP tool.
Its model endpoint is provided by OpenShift AI MaaS.

== Test an image on the T4

[source,sh,role=execute]
----
D3_URL=http://d3-mini.decision-serving.svc.cluster.local:8080
CARD_SCOUT_URL=http://card-scout-platform.signal-desk-dev.svc.cluster.local:8080
curl --fail-with-body -sS "$D3_URL/v1/models" | \
  jq '{id:.data[0].id,device:.data[0].device,dtype:.data[0].dtype}'
curl --fail-with-body -sS "$CARD_SCOUT_URL/assets/item-039" -o /tmp/card-scout.png
base64 -w0 /tmp/card-scout.png > /tmp/card-scout.b64
jq -n --rawfile image /tmp/card-scout.b64 '{
  model:"vllm-sr/d3-mini",
  state:"Inspect the attached image and classify the trading card.",
  images:["data:image/png;base64," + $image],
  questions:{
    card_kind:{type:"choice",instructions:"Is this a Pokemon TCG card?",criteria:{pokemon_tcg:"A Pokemon Trading Card Game card",other_card:"Another card game",not_a_card:"Not a trading card",uncertain:"Cannot determine"}},
    rarity:{type:"choice",instructions:"Read the printed rarity. A classic circle is Common, diamond Uncommon, star Rare. Character popularity is not rarity.",criteria:{common:"Common",uncommon:"Uncommon",rare_or_higher:"Rare or a higher rarity tier",not_applicable:"Not a Pokemon TCG card",uncertain:"Rarity cannot be determined"}}
  }
}' > /tmp/card-scout-decision.json
curl --fail-with-body -sS --max-time 120 "$D3_URL/v1/systemone" \
  -H 'Content-Type: application/json' --data-binary @/tmp/card-scout-decision.json | jq '.answers'
----

Expect `device: cuda:0` and `dtype: float16`. D3 needs no API key. The image is
Toedscool from Scarlet & Violet; compare the returned choices and probabilities.
A model probability is not a calibrated guarantee or a price prediction.

== Test DeepSeek through MaaS

[source,sh,role=execute]
----
curl --fail-with-body -sS --max-time 180 "${OPENAI_BASE_URL}/chat/completions" \
  -H "Authorization: Bearer $OPENAI_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model":"deepseekv4pro","messages":[{"role":"user","content":"In one sentence, explain why a trading card rarity is different from its market value."}],"max_completion_tokens":256}' | jq '{model,answer:.choices[0].message.content,usage}'
----

Expect an actual answer and measured usage. A quota error is a visible failure;
do not switch the workshop model or substitute a keyword rule.

== Test the native agent and its tool

For this probe, use the injected developer MaaS key with the native Responses
API. The prepared service has a separate runtime key for application research.

[source,sh,role=execute]
----
PROVIDER_DATA=$(jq -cn --arg key "$OPENAI_API_KEY" '{vllm_api_token:$key}')
jq -n --arg mcp "$CARD_SCOUT_URL/mcp" '{
  model:"maas-vllm-inference-1/deepseekv4pro",
  input:"Use get_card_market_data once for item-039. Report its exact catalogue identity and Cardmarket EUR trend, 7-day average, update timestamp and source. Do not invent missing prices.",
  tools:[{type:"mcp",server_label:"card_scout_market",server_url:$mcp,require_approval:"never",allowed_tools:["get_card_market_data"]}],
  tool_choice:{type:"mcp",server_label:"card_scout_market",name:"get_card_market_data"},
  max_infer_iters:4,reasoning:{effort:"none"},store:false
}' > /tmp/card-scout-agent.json
curl --fail-with-body -sS --max-time 180   http://lsd-genai-playground-service.signal-desk-dev.svc.cluster.local:8321/v1/responses \
  -H "X-OGX-Provider-Data: $PROVIDER_DATA" -H 'Content-Type: application/json' \
  --data-binary @/tmp/card-scout-agent.json | jq '{status,output,usage}'
unset PROVIDER_DATA
----

Check `status: completed`, an actual `mcp_call` for `item-039`, and dated source
data. A plausible answer without the tool call is not a successful test.
Prices can be missing; do not replace them with a guess.

The generated application will use only the prepared Card Scout API. All three
model/tool paths remain owned by the platform.
