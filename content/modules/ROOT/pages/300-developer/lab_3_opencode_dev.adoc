= Lab 2.3 — Build and Ship Signal Desk

Use DeepSeek in OpenCode to build the game described by `APP_CONTRACT.md`, keeping the prepared delivery scaffold. The reference supplies working API clients and replay rules so the exercise focuses on the app rather than inventing model protocols.

[NOTE]
====
*Persona:* Developer +
*Time:* 35–45 minutes, plus the first scoring pass +
*Outcome:* English app, generated/adapted with DeepSeek, built by Tekton and deployed by your own Argo CD.
====

The model API checks in Lab 2.2 must pass before this exercise. The repository includes a fixed Techmeme snapshot for 26–28 October 2026. The app scores these saved articles, freezes virtual investments, then compares the first market open after the snapshot cutoff with the latest available market quote. Quotes are timestamped and may be delayed.

== Step 1: Read the contract

In the *Dev Spaces terminal*:

[source,sh,role=execute]
----
cd "${PROJECT_SOURCE}"
cat APP_CONTRACT.md
oc auth can-i create pipelineruns -n "${APP_NAME}-build"
oc auth can-i create deployments -n "${APP_NAME}-dev"
opencode
----

Expect both permissions to be `yes`. Do not give the coding model administrator credentials or ask it to change SCC/RBAC.

OpenCode reads the project runbook. Press kbd:[Tab] to switch between *plan* (read-only) and *build* (writes files); use `/exit` to return to the shell.

== Step 4: Play one round

Open the public HTTPS app Route.

. Read the default semiconductor fund memo; expand it if you want to change the fund.
. Expand *News & sources* and click *Load saved news*. The app reads the JSON bundled from the repository and ranks its 161 articles on the T4. No Techmeme download or manual import is required.
. Check the displayed news dates and collection provenance. *Export news* includes the saved sources and scores; these are headlines and short excerpts, not full publisher articles.
. Open an interesting story and click *Find stock opportunities*. Expect a hypothetical thesis and risk for verified company shares, including supported suppliers, customers or competitors. A high relevance score alone is not a BUY instruction.
. Check *View MLflow trace*: it opens this research in the prepared workspace and experiment.
. Add a virtual amount to one or more ideas. Stay within $10,000. No return should be revealed yet.
. Click *Reveal result*. The complete portfolio freezes before market prices are requested. Expand *Prices & calculation* to inspect entry/exit dates and the price-data source.
. Check the quote timestamp. *Update result* fetches the latest available price without changing choices. *Try another story* starts a fresh budget and retains the previous round.

The fixed input is https://github.com/fjcloud/aro-ai-app-platform/blob/main/examples/briefing-desk/news/techmeme.json[news/techmeme.json]. Its news cutoff is 29 October at 00:05 New York time; entry is each stock exchange’s first session open afterward. Foreign share prices are converted to the USD paper fund using explicit FX references. Valuation uses the latest available regular-market quote, including an intraday quote. Before opening, on weekends or holidays, its actual timestamp shows which session it belongs to.

The same saved news can be replayed in later workshops. Only market data is refreshed. This is an educational retrospective comparison; returns exclude dividends, fees and slippage.

If a model, archive or price provider is unavailable, the UI must show the error and preserve progress. Do not replace inference with a keyword rule or invented output.

== Step 5: Ship a small change

Ask OpenCode, in *build* mode:

[source,text,role=execute]
----
Remember the existing “High relevance only” preference in browser localStorage. Restore it when the page reloads, including when no stories match. Keep the initial three-story view, the filtered count and the checkbox’s accessible name. Keep the archived corpus export, saved portfolio, scoring, agent tools, HTTPS and replay rules unchanged. Test it, commit and push, then rebuild and deploy with AGENTS.md. Wait for the new Git revision and rollout before reporting success.
----

Verify the new UI on the Route. In the Dev Spaces terminal:

[source,sh,role=execute]
----
oc annotate application "$APP_NAME" -n "${APP_NAME}-dev" \
  argocd.argoproj.io/refresh=hard --overwrite
oc wait application/"$APP_NAME" -n "${APP_NAME}-dev" \
  --for=jsonpath='{.status.sync.revision}'="$(git rev-parse HEAD)" --timeout=180s
oc get application "$APP_NAME" -n "${APP_NAME}-dev" -o json | \
  jq '{revision:.status.sync.revision,sync:.status.sync.status,health:.status.health.status}'
oc rollout restart deployment/"$APP_NAME" -n "${APP_NAME}-dev"
oc rollout status deployment/"$APP_NAME" -n "${APP_NAME}-dev" --timeout=180s
EXPECTED_DIGEST=$(oc get istag "${APP_NAME}:latest" -n "${APP_NAME}-build" -o jsonpath='{.image.metadata.name}')
oc get pods -n "${APP_NAME}-dev" -l "app.kubernetes.io/name=${APP_NAME}" -o json | \
  jq -e --arg name "$APP_NAME" --arg digest "$EXPECTED_DIGEST" \
  '[.items[].status.containerStatuses[] | select(.name==$name)] | length > 0 and all(.[]; .ready and (.imageID | endswith("@"+$digest)))'
ROUTE=$(oc get route "$APP_NAME" -n "${APP_NAME}-dev" -o jsonpath='{.spec.host}')
curl --fail-with-body -sS "https://${ROUTE}/healthz" | jq .
----

You have generated/adapted an app with DeepSeek, played a real-price replay and shipped a second revision through the same delivery path.
