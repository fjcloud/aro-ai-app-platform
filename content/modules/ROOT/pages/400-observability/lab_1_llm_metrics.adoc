== The coding model rate

Example rates checked on *22 October 2026*, Global Standard, East US 2. These are public list rates, not a quote for your account:

The https://prices.azure.com/api/retail/prices?$filter=productName%20eq%20%27Azure%20Deepseek%20Models%27%20and%20armRegionName%20eq%20%27eastus2%27[Azure Retail Prices API] lists these Global rates in USD per 1K tokens. The table below converts them to 1M tokens; check the current rates when running the workshop.

[cols="1,1", options="header"]
|===
| Meter | Per 1 million tokens

| Input
| $1.74

| Cached input
| $0.145

| Output, including reasoning tokens
| $3.48
|===

An idle Global Standard deployment has no token usage charge. Its account key remains valid while the account exists. Remove the workshop deployment after all users have finished; deleting a deployment does not revoke the account key.

== Part 1: Read one usage object

In the Dev Spaces terminal, `$OPENAI_BASE_URL` and `$OPENAI_API_KEY` already point to MaaS. If you use the bastion terminal, load the injected MaaS credential first:

[source,sh,role=execute]
----
if [[ -z "${OPENAI_BASE_URL:-}" ]]; then
  OPENAI_BASE_URL=$(oc get secret ai-provider-openai-api-key -n openshift-operators \
    -o jsonpath='{.data.OPENAI_BASE_URL}' | base64 -d)
  OPENAI_API_KEY=$(oc get secret ai-provider-openai-api-key -n openshift-operators \
    -o jsonpath='{.data.OPENAI_API_KEY}' | base64 -d)
fi

curl --fail-with-body -sS --max-time 180 "${OPENAI_BASE_URL}/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{"model":"deepseekv4pro","messages":[{"role":"user","content":"Reply with one short sentence."}],"max_completion_tokens":256}' \
  | python3 -m json.tool
----

MaaS reports the same upstream usage while enforcing the workshop subscription allowance. In OpenShift AI, inspect *Settings → MaaS governance → deepseekv4pro-workshop* to distinguish that allowance from Azure billing.

Find `usage`. A typical short reply looks like this:

[source,json]
----
"usage": {
  "prompt_tokens": 12,
  "completion_tokens": 18,
  "total_tokens": 30
}
----

Price that call:

[source]
----
uncached_input = prompt_tokens - cached_input_tokens
dollars = uncached_input / 1_000_000 * 1.74
        + cached_input_tokens / 1_000_000 * 0.145
        + completion_tokens / 1_000_000 * 3.48
----

Use the cached input count from `usage.prompt_tokens_details.cached_tokens` when provided, otherwise use zero for this estimate. Do not add reasoning tokens again when they are already included in `completion_tokens`.

Twelve input tokens and eighteen output tokens are a fraction of a cent. An OpenCode session is larger because it sends `AGENTS.md` and the conversation on every turn, and reasoning tokens count as output.

== Part 2: Estimate the session cost

Use recorded OpenCode usage if available. Otherwise use these illustrative, uncached-input examples. They are not measured workshop totals:

| One OpenCode turn that sends the runbook

Whisper’s T4 worker, the additional CPU worker (if added), and storage are not on the Foundry token invoice. The cluster workers are the other line: your assigned environment's worker VMs are billed while they exist. Worker counts and VM sizes depend on the RHDP environment.

== Part 3: Facilitator cleanup — coding deployment

After *all participants* finish using OpenCode, the facilitator runs this in the *bastion terminal*, in the workshop repository. On a single-user assignment, you perform this step yourself. It revokes the injected MaaS key, removes the external-model publication and provider Secret, and deletes the Azure coding deployment. It leaves the Foundry account and its keys in place. Do not remove resources used by another workshop.

[source,sh,role=execute]
----
cd "$HOME/aro-ai-app-platform"
set -a
source state/foundry.env
set +a

MAAS_HOST=$(oc get gateway maas-default-gateway -n openshift-ingress \
  -o jsonpath='{.spec.listeners[0].hostname}')
KEY_ID=$(oc get secret ai-provider-openai-api-key -n openshift-operators \
  -o jsonpath='{.metadata.annotations.workshop\.fjcloud\.io/maas-key-id}')
if [[ -n "$KEY_ID" ]]; then
  curl --fail-with-body -sS --max-time 60 -X DELETE \
    "https://${MAAS_HOST}/maas-api/v1/api-keys/${KEY_ID}" \
    -H "Authorization: Bearer $(oc whoami -t)"
fi
oc delete externalprovider.inference.opendatahub.io foundry -n llm-serving --ignore-not-found
oc delete secret foundry-provider-key -n llm-serving --ignore-not-found
oc delete -k deploy/coding --ignore-not-found

az rest --method delete \
  --url "https://management.azure.com/subscriptions/${SUBSCRIPTION}/resourceGroups/${RESOURCEGROUP}/providers/Microsoft.CognitiveServices/accounts/${FOUNDRY_NAME}/deployments/${DEPLOYMENT}?api-version=${API}"
oc delete secret ai-provider-openai-api-key -n openshift-operators --ignore-not-found
----

== Part 4: Facilitator cleanup — speech infrastructure

The model is shared. Keep it available while participants test their apps. Deleting the model pod alone does not stop the VM or disk charges.

[source,sh,role=execute]
----
# Remove only workshop speech resources, not the assigned RHDP cluster.
oc delete -k deploy/speech
oc delete machineset -n openshift-machine-api \
  -l workshop.fjcloud.io/experiment=t4
oc delete machineset -n openshift-machine-api \
  -l workshop.fjcloud.io/speech-capacity=true
oc get machines -n openshift-machine-api
----

Wait for the labelled workers to disappear and check the Azure resource group. The original CPU MachineSets remain. This also deletes the Whisper model cache PVC; Azure may take time to reclaim its disk. The operator installations remain available for later exercises.

== Act 3 checkpoint

* You can distinguish coding token charges from GPU, CPU and disk charges.
* You priced a response from its `usage`, or labelled the worked example as an estimate.
* After everyone finishes, the facilitator confirms the coding deployment and labelled speech workers are removed, and checks disk reclamation in Azure. Existing workspaces can retain injected credentials until stopped. The revoked MaaS key cannot be reused; any additional keys expire within 24 hours or can be revoked in the MaaS dashboard.

The Go app’s `/healthz` can stay healthy after model cleanup, but transcription then fails because Whisper is gone. Test the app *before* cleanup. Never delete the assigned RHDP cluster or its original CPU workers.
