= Conclusion

You used two models for two different jobs:

* *DeepSeek on Foundry* powered OpenCode in Dev Spaces.
* *Whisper on one T4* transcribed the application’s audio through OpenShift AI, KServe and Red Hat AI Inference.

The Go application captured microphone audio in the browser, sent short WAV clips through its backend, and displayed the transcript. Tekton built the image; your project’s Argo CD deployed it. The model service stayed inside the cluster.

This is *near-real-time transcription*: results arrive after each short clip. Whisper is not a native continuous streaming model. Test accents, background noise, long sentences and slow networks before using this pattern beyond a workshop.

== Costs and cleanup

Foundry charges for coding tokens. The T4 VM, ARO worker licence and disks are billed while provisioned, even when nobody speaks. Deleting or stopping the Whisper pod alone does not remove those costs.

Follow Lab 3.1 for scoped cleanup. Never delete the shared RHDP cluster. On a multi-user workshop, only the facilitator removes the shared inference service, model cache and GPU worker after all participants finish.
