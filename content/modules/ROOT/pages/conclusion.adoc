= Conclusion

You prepared complementary AI capabilities:

* *DeepSeek through OpenShift AI MaaS* generated the Go application and powered
  the native price agent, using separate coding and runtime credentials.
* *d3-mini on one T4*, served by OpenShift AI/KServe, classified a mixed-era
  collection from real card images.

Card Scout's small generated UI used a prepared platform API for analysis,
ranking, catalogue verification and dated market prices. Tekton built its image;
Argo CD delivered the exact Git revision. The Playground exercised the same MCP
tool, and MLflow exposed model inputs, tool evidence and outputs.

A model prediction can differ from catalogue rarity. Rarity is distinct from
market value; provider aggregates do not determine a physical card's condition,
authenticity or final sale price.

== Costs and environment lifetime

MaaS token usage and GPU utilization are different measurements. Foundry charges
for tokens; the T4 VM, CPU workers and disks remain provisioned while idle.
The RHDP environment expires on its assigned schedule. Export your code before then.
