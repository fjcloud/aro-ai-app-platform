Instructions

Terminal address:

Paste the lab export, then Create. The page starts an Azure CLI container in the lab resource group and attaches the terminal on the right. It signs in as the service principal. Paste the deploy command into that terminal.

  1. The export looks like GUID, CLIENT_ID, PASSWORD, TENANT, SUBSCRIPTION, and RESOURCEGROUP. Paste the whole block. The secret is used only to sign in, then it is dropped. It is not in the command preview.
  2. Quota on that subscription, in the resource group's region: at least 24 vCPUs of Standard DSv3 Family and 24 vCPUs of Standard NCADS_A100_v4 Family. The terminal itself uses 1 vCPU and 2 GB.
  3. Choose Create. The first start pulls the Azure CLI image, which can take a few minutes. Later starts attach to the same container.
  4. Put your pull secret at ~/pull_secret.json in that terminal. It must include registry.redhat.io, registry.connect.redhat.com, and cloud.openshift.com.
  5. Paste with Ctrl+Shift+V (Ctrl+V in some browsers, ⌘+V on a Mac). The command runs make deploy in RESOURCEGROUP. The cluster name is aro- plus the GUID.
  6. Stay in that shell for the later oc labs. To continue on your laptop, download ~/aro-ai-app-platform/state/kubeconfig. The API is public. make delete removes the cluster and keeps the lab resource group. Remove terminal deletes only the CLI container.

Cluster create takes about 40 minutes. Pasting the command again finishes whatever step stopped. Lab 1.1, make gpu, comes after the workers are up. The service principal needs permission to create Entra app registrations; that is how the console login is created. The container keeps running, and billing, until you remove it.
